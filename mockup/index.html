Bashreactor

A resumable pipeline runner for bash: one YAML file says what runs, every step is one bash file, and a run is a directory you can restart.

mockup

The three screens

1 editor Pipeline Write the YAML. The graph is drawn from it, never stored beside it, so the two cannot drift. 2 live Runs A run streaming its logs and step states, with cancel and retry, the way it would read the API. 3 library Blocks The library of bash files. Their front matter says what goes in and what comes out.

State of the project

The spec has landed, and this mockup is built against the data the API will return: run.json and the block files. Nothing on these pages runs; the data is fake and the logs are replayed.

  • The pipeline text, block files and run fixtures follow docs/SPEC.md.
  • The engine, store, API, MCP server, CLI and web app are not built yet.
